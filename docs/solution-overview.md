# Solution Overview

## PortMind AI — Intelligent Container Congestion Prediction & Port Operations Optimisation Platform

### Core Concept

PortMind AI transforms port operations from **reactive** to **predictive** through a unified workflow:

```
PREDICT → EXPLAIN → OPTIMIZE → PLAN
```

Traditional port systems show what is happening now. PortMind AI shows what will happen — and what to do about it.

### Five Core Modules

#### Module 1 — Vessel & Schedule Management
A comprehensive vessel tracking system showing arrival/departure schedules, berth assignments, congestion risk scores, and operational status for every vessel in the system.

#### Module 2 — Congestion Prediction Engine
An analytical scoring model that calculates congestion probability across 6H, 12H, 24H, and 72H prediction horizons. The model uses five weighted factors: berth utilization, vessel queue size, arrival rate, crane availability shortfall, and large-vessel ratio.

> **Transparency note:** This is an analytical scoring model using synthetic demo data. It is not a trained machine-learning model. Predictions are clearly labelled as such in the UI.

#### Module 3 — Root-Cause Analysis
When congestion is predicted, the system explains exactly why — which terminals are affected, which factors are dominant, and what the operational impact will be. Explanations are generated by IBM watsonx.ai using actual computed data, not hallucinated facts.

#### Module 4 — Berth & Crane Optimization
A constraint-based optimization engine that compares the current operational plan against an AI-recommended plan. Shows vessel-to-berth assignments, crane allocations, and conflict detections — with clear explanations for every recommendation.

#### Module 5 — AI 72-Hour Operations Copilot
An IBM watsonx.ai-powered assistant that answers natural-language questions about port operations and generates structured 72-hour operations plans with prioritized actions across four time windows.

### AI Design

**Three-layer AI architecture:**

1. **Deterministic Analytics Layer** — Calculates all operational numbers (utilization, scores, waiting times)
2. **Deterministic Optimization Layer** — Produces berth/crane assignment recommendations
3. **IBM watsonx.ai Layer** — Generates natural-language explanations and operations plans

> The LLM never invents operational facts. It only reasons about and narrates data that has been computed by deterministic engines.

### Innovation Differentiators

| Feature | Traditional Port Systems | PortMind AI |
|---|---|---|
| Congestion awareness | Current state only | Predicted 6H–72H ahead |
| Root cause | Manual investigation | AI-explained, data-grounded |
| Berth assignment | Manual scheduling | Algorithm-optimized with conflict detection |
| Crane allocation | Ad-hoc | Demand-based with utilization balancing |
| Operations planning | Informal | Structured 72-hour AI-generated plan |
| Operator interface | Multiple disconnected tools | Single unified command center |
