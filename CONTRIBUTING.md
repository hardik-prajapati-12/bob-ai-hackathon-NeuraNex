# Contributing to PortMind AI

Thank you for your interest in contributing to PortMind AI.

## Development Setup

See [docs/setup-guide.md](docs/setup-guide.md) for setup instructions.

## Project Structure

```
src/
  backend/   — Node.js + Express REST API
  frontend/  — React + Vite application
docs/        — Documentation
demo/        — Screenshots and demo script
presentation/ — Presentation slides
```

## Code Standards

- Follow existing code style and patterns
- Write meaningful commit messages
- Add comments where they improve understanding
- Keep business logic out of React components
- Keep database logic in the service layer

## Submitting Changes

1. Create a feature branch
2. Make your changes
3. Test thoroughly
4. Submit a pull request with a clear description
